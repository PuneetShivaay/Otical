# 00 — Project Brief

> The "why" behind the Otical website. Read this before changing copy, structure, or design.

## Company

**Otical** is a full-service technology partner — not a single-product company.
We take a client from strategy → design → build → deploy → secure → scale.

## Positioning

**Primary line:** _One partner. Every layer of your digital stack._
**Short lockup:** _Technology, end to end._

The core messaging problem: 9 services can read as "unfocused". Every page must
reframe breadth as **integrated capability** — one accountable team across the stack.

## Audience

- Founders / SMB owners needing a complete build partner
- Product & marketing leads needing design + engineering
- Enterprises needing specialist capability (cloud, security, blockchain, AI)

## Goals (in priority order)

1. **Credibility** — prove capability with real work, real team, real clients
2. **Qualified enquiries** — contact form captures service + budget + timeline
3. **Discoverability** — per-page SEO metadata, structured data, fast Core Web Vitals
4. **Performance** — speed *is* the premium signal; Lighthouse 95+ target

## Proof assets available

- **24 real client logos** — all publicly displayable
- **3–4 full case studies** (e.g. PetMets — live at petmets.in); rest stay logo-only
- **9 team members** with photos + LinkedIn
- **6 client testimonials** tied to named companies

## Explicitly out of scope

- **Pricing tables** — removed; agency work is scoped, not priced off-the-shelf
- **Hero video** — removed for performance
- A CMS — content lives in `data/` as typed plain objects
